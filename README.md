PhonePe Data Analysis – Python Project
🔍 Overview
This repository contains a Python-based data analysis project that explores digital payment trends in India using PhonePe transaction data.
The project is designed to showcase data analysis skills commonly used in real-world analytics and data science roles.

🧰 Tech Stack


Python


Pandas


NumPy


Matplotlib


Seaborn


Jupyter Notebook



📂 Dataset Information
The dataset contains:


State


Year


Transaction Count


Transaction Amount


Transaction Type


This data helps analyze how digital payments have evolved across different regions in India.

📈 Key Analysis Performed

Year-wise transaction growth analysis

State-wise comparison of transaction volume and value

Identification of:

Top 5 states by transaction volume

Bottom 5 states by transaction volume

Trend analysis using aggregations and visualizations

Clean and readable plots for business insights

🧠 Key Insights

Digital transactions show consistent year-over-year growth
Metro and high-population states dominate transaction volume
Emerging states show rapid adoption in recent years

Certain transaction categories contribute more to overall value
